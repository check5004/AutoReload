# AutoReload のインストール・更新

Chrome 120 以降のデスクトップ版が対象です。ストアからのインストールは不要です。

## はじめて使う

1. GitHub の Releases から **AutoReload-vX.Y.Z.zip** をダウンロードします。「Source code」や「Lab」のZIPは拡張機能用ではありません。
2. ZIPを展開し、中の **AutoReload** フォルダーを、削除しない固定の場所へ移します（例：`Documents/ChromeExtensions/AutoReload`）。
3. Chrome のアドレスバーに `chrome://extensions` を入力します。
4. 右上の「デベロッパー モード」をONにします。
5. 「パッケージ化されていない拡張機能を読み込む」で、`manifest.json` が直接入っている **AutoReload** フォルダーを選びます。
6. Chrome のパズルアイコンから AutoReload をピン留めします。
7. 購入ページまたは練習サイトを開き、AutoReload のアイコンから「このドメインで使う」をONにし、サイトへのアクセスを許可します。

ソースから使う場合は、このリポジトリの **extension** フォルダーを指定できます。ビルドや依存パッケージのインストールは不要です。

## 更新する

新版があると、AutoReload のポップアップ下部に小さな案内が表示されます。デスクトップ通知、強制表示、自動ダウンロードはありません。

1. 実行中の復旧監視・入力補助を停止します。必要なら設定画面でバックアップを書き出します。
2. 新しいZIPを展開し、**今まで読み込んでいた AutoReload フォルダー内を、新しいファイルで置き換えます**。フォルダーの場所を変えないでください。
3. `chrome://extensions` の AutoReload カードにある再読み込みボタンを押します。拡張機能を削除・再インストールする必要はありません。
4. 対象のWebページも再読み込みします。バージョンと設定を確認してから監視を開始します。

拡張機能のIDを固定する公開鍵を同梱しているため、同じ拡張機能として設定を引き継げます。拡張機能を「削除」すると保存データも消えます。

GitHubから手動導入した拡張機能は、Chromeの自動更新の対象ではありません。更新案内から上の手順で更新してください。

## よくあるつまずき

- **パネルが出ない**：そのドメインをONにしたか確認してページを再読み込みします。Chrome内部ページ、Chromeウェブストア、PDFビューアー、`file://` は対象外です。
- **別のドメインへ移った**：それぞれのドメインでONにしてください。自動実行はドメインをまたぐと停止します。
- **復旧しても止まらない**：「復旧の目印を覚える」で販売画面の見出しを指定するか、「復旧したと判定する文字」を設定してください。
- **ブラウザーの接続エラー画面になった**：Chrome自身のエラー画面には拡張機能のパネルを挿入できません。手動で再読み込みしてサイトへ戻してください。
- **時刻を過ぎても動かない**：PCのスリープ解除・タブを開いたままにする・ブラウザーのメモリセーバー対象外にする、を確認します。正確な時刻での実行保証はありません。
- **入力されない**：まず「対象を確認（実行なし）」を使います。iframe内、閉じたShadow DOM、サイト独自の特殊コントロールには対応しません。

アクセス権限はChromeのサイト単位です。設定はさらに origin（スキーム・ホスト・ポート）ごとに分離します。`https://example.com` と `https://tickets.example.com` は別設定です。
