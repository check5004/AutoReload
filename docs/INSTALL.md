# AutoReload の入れ方・更新のしかた

AutoReloadは、パソコン版Google Chromeに追加して使う道具です。Chrome 120以降に対応しています。スマートフォン版Chromeには入れられません。

## はじめて使う

1. **[ダウンロードページ](https://github.com/check5004/AutoReload/releases/latest)** を開き、下の方の **Assets** （配布ファイルの一覧）から **AutoReload-v数字.zip** を押します。たとえば `AutoReload-v0.2.0.zip` です。数字は版によって変わります。「Source code」は選びません。
2. ダウンロードしたZIPを **展開** して、中身を取り出します。Windowsでは右クリック →「すべて展開」、Macではダブルクリックします。
3. 中にある **AutoReloadフォルダー** を、ドキュメントなど今後も残しておく場所へ移します。使っている間は、このフォルダーを削除・移動しないでください。
4. Chrome上部のアドレス欄に `chrome://extensions` と入力し、Enterを押します。
5. 開いた管理画面の右上で **「デベロッパー モード」** をONにします。ストア以外の場所から入れるための切り替えです。プログラミングの作業はありません。
6. **「パッケージ化されていない拡張機能を読み込む」** を押し、手順3の **AutoReloadフォルダー** を選びます。中に `manifest.json` というファイルが見えるフォルダーが正解です。ZIPや外側のフォルダーは選びません。
7. Chrome右上の **パズルの形のアイコン** を押し、AutoReloadの横にある **ピンのボタン** を押します。右上にAutoReloadのアイコンが出ます。
8. AutoReloadのアイコンを押し、 **「練習ページ」** を選びます。購入のない練習ページがChromeの別のタブで開きます。

配布ZIPには練習ページも入っています。練習用に別のアプリを起動する必要はありません。

## 最初の練習

1. 練習ページの左側で「混雑からの復旧」を選びます。
2. 「混雑ページから復旧するまで」を「10秒」にし、「この条件で練習する」を押します。
3. ページ右下の小さな ↻ を押して「復旧監視を開始」を押します。
4. 数十秒待ち、何度かページが読み直されてから販売画面に戻り、「復旧しました」と表示されることを確認します。

練習は初回からONになっています。自分でOFFにした場合は、練習ページでChrome右上のAutoReloadアイコンを押し、「このページで使う」をONに戻します。

練習で覚えた操作や入力値は、練習用の設定として保存します。本物の購入サイトの設定とは別です。入力の練習は、練習ページの「使い方」または **[入力補助の練習手順](https://github.com/check5004/AutoReload/blob/main/docs/INPUT-GUIDE.md)** を参照してください。

実際のサイトでは、そのページで右上のAutoReloadアイコンを押し、「このページで使う」をONにしてサイトへのアクセスを許可します。 **ONは準備の状態です。** 「復旧監視を開始」や「入力補助を実行」を押すまでは動きません。

## 更新する

新版があると、Chrome右上のAutoReloadアイコンを押したときに、小さく案内が出ます。ファイルのダウンロードや入れ替えは自分で行います。

1. 実行中の監視・入力補助を「停止」で止めます。
2. 必要なら、設定画面の「このページの設定を書き出す」でバックアップを保存します。複数のサイトで使っている場合は、必要なサイトごとに書き出します。ファイルには名前などの入力値も入るため、自分で保管してください。
3. **[ダウンロードページ](https://github.com/check5004/AutoReload/releases/latest)** から新しいZIPを保存して展開します。
4. 新しく取り出したAutoReloadフォルダーを開き、 **中のファイルとフォルダーをすべて、今まで使っていたAutoReloadフォルダーの中へコピーします** 。同じ名前のファイルを置き換えるか聞かれたら、置き換えます。AutoReloadフォルダーの中に、さらにAutoReloadフォルダーを作るのではありません。
5. Chromeで `chrome://extensions` を開き、AutoReloadと書かれた枠にある **再読み込みのボタン ↻** を押します。
6. 使う購入ページや練習ページも、Chromeの更新ボタンで読み直します。
7. 設定が残っていることを確認してから使い始めます。

**今まで使っていたフォルダーの場所は変えず、拡張機能を「削除」しないでください。** 削除すると、保存した設定も消えます。ストア経由ではないため、Chromeが自動で新版に置き換えることはありません。

## つまずいたとき

| 状況 | 対処 |
| --- | --- |
| 読み込むフォルダーがわからない | フォルダーを開き、`manifest.json` が直接入っているか確認してください。ZIPは先に展開します。 |
| 右上にアイコンが見つからない | Chromeのパズルアイコンを開き、AutoReloadをピン留めしてください。 |
| 右下の小さなボタンが出ない | そのページでAutoReloadをONにしたか確認し、ページを読み直してください。 |
| 読み込んだ後でフォルダーを移動してしまった | まず元の場所に戻し、Chromeの拡張機能管理画面で再読み込みしてください。 |
| 「このサイトにアクセスできません」と出ている | Chrome自身のエラー画面には操作ボタンを出せません。手動でページを読み直してください。 |
| 旧版の練習サイトを使っていた | 0.2.0から練習ページを拡張機能に内蔵しました。右上のメニューから開いてください。旧サイト用の設定は残りますが、内蔵ページには自動移行しません。 |
