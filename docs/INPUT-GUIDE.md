# 入力補助を、購入のない練習ページで試す

[READMEに戻る](../README.md)

この練習では「公演を選ぶ → 名前・メール・来場日・枚数を入れる → 内容を確認する」をAutoReloadに教えます。最後に日付だけ変え、発売後に現れる公演を選べるか試します。実際の申込や決済はありません。

## 1. 練習する公演と入力値を決める

1. Chrome右上のAutoReloadアイコンから「練習ページ」を開きます。
2. 左側の「前日の準備」を選び、「目的の公演日」を `2026-10-14`、「席種」を `S席` にします。
3. 「この条件で練習する」を押します。右側に、公演ごとの「受付開始前」ボタンが並びます。
4. 上部の「練習用の設定を開く」を押します。別のタブに設定画面が開きます。
5. 左上の「設定するページ」が「内蔵の練習ページ」になっていることを確認し、次の値を入れて「設定を保存」を押します。

| 設定画面の欄 | 練習用の入力例 |
| --- | --- |
| 目的の公演日 | `2026-10-14` |
| 席種・グレード | `S席` |
| お名前 | `練習 花子` |
| メールアドレス | `practice@example.com` |
| 枚数 | `2` |

Chrome上部のタブを押して、練習ページに戻ります。ここで使う名前やメールは架空のものです。

**練習ページ左側の条件は「どんな販売画面を再現するか」、設定画面の値は「AutoReloadにどの公演を選ばせ、何を入力させるか」です。** この2か所の公演日・席種をそろえてください。

## 2. 公演を選ぶボタンを教える

1. 練習ページ右下の **↻** を押し、 **「項目を覚える」** を押します。
2. **`2026-10-14 / S席` の行** にある **「受付開始前」** ボタンをクリックします。まだ押せない発売前のボタンでも、記録できます。
3. 出てきた記録画面で「操作」が **「クリックして進む」** になっていることを確認します。
4. **「対象に含まれる文字」** に、次の1行を入れます。練習ページでは自動で入ることもあります。

```text
{{date}} | {{grade}}
```

5. **「この操作を保存」** を押します。

`{{date}}` は設定画面の「目的の公演日」、`{{grade}}` は「席種・グレード」を使う指定です。真ん中の `|` は「両方の文字があるものを探す」という意味です。この例なら、周りに「2026-10-14」と「S席」の両方が書かれたボタンを探します。

**記録中にクリックしても、そのボタンの操作は実行されません。** 今は公演選択の画面にとどまっていて正解です。

## 3. 入力欄を1つずつ教える

公演一覧の下にある **「入力欄も準備する」** を普通に押します。練習用の入力画面が開きます。

次の各項目について、 **「項目を覚える」→対象の欄をクリック→指定を確認→「この操作を保存」** を繰り返します。最初の1回で、すべての欄をまとめて覚える仕組みではありません。

| 順番 | クリックする場所 | 「操作」で選ぶもの | 「入力・選択する値」に書くもの |
| --- | --- | --- | --- |
| 1 | お名前の入力欄 | 入力する | `{{name}}` |
| 2 | メールアドレスの入力欄 | 入力する | `{{email}}` |
| 3 | 来場日の入力欄 | 入力する | `{{date}}` |
| 4 | 枚数の選択欄 | 選択肢を選ぶ | `{{quantity}}` |
| 5 | 内容を確認するボタン | クリックして進む | 入力不要 |

入力欄の「対象に含まれる文字」は空欄で構いません。上の値が自動で入った場合も、保存前に確認してください。記録だけでは名前などが実際に入力されなくても正常です。

## 4. 覚えた順番と入力先を確認する

1. 上部の「練習用の設定を開く」で設定画面を開きます。
2. 今回覚えた操作が、公演の選択から内容の確認まで **6件** あることを確認します。上から順に実行されます。順番が違う場合は **↑ / ↓** で並べ替えます。以前の練習で覚えた操作が残っている場合は、そちらの「この操作を使う」のチェックを外してから保存してください。
3. 名前の操作の **「対象を確認（実行なし）」** を押します。練習ページへ戻り、対象の欄が数秒間、青枠で示されます。ここでは入力もクリックも行いません。

公演ボタンは公演一覧の画面、名前の欄は入力画面で確認してください。今の画面に存在しない項目は、プレビューでも見つかりません。

## 5. 日付を変えて、発売開始を待つ

1. 設定画面の「目的の公演日」を **`2026-10-15`** に変更して「設定を保存」を押します。覚えた6件の操作はそのまま使います。
2. 練習ページに戻り、左側の「目的の公演日」も **`2026-10-15`** に変えます。席種は両方とも `S席` のままにします。
3. **「発売開始を待つ」** を選び、「発売まで」を **15秒** にします。
4. 「翌日は項目のID・並び順を変える」はONのままにします。これは、見た目の並びやサイト内部の項目名が変わっても見つけられるかを試す切り替えです。
5. **「この条件で練習する」** を押し、続けて右下の **↻ →「入力補助を実行」** を押します。
6. 発売後に10月15日の公演が現れ、選択・入力・内容確認まで進むことを確かめます。
7. 最終確認の内容を読みます。「購入を確定する（練習）」は自分で押せます。実際の購入は発生しません。

日付に `{{date}}` と指定した操作は、新しい設定の日付を使います。`2026-10-14` と直接記録した操作は、そのままでは10月14日を使い続けます。

本当の購入サイトでは、日付の書き方やページの構造が異なることがあります。練習用の操作は購入サイトへ移らないので、そのサイトでも入力先を教え、プレビューで確認してください。

## 混雑から戻った後、入力まで続けるには

同じ操作を覚えた状態で、練習ページの「混雑からの復旧」を選びます。公演日・席種を設定画面とそろえて「この条件で練習する」を押し、 **「入力補助を実行」** を開始してください。

混雑画面ではリロードして待ち、戻ると覚えた操作を進めます。「復旧監視を開始」を選んだ場合は、戻ったことを確認したところで止まり、入力は始まりません。

## 決めた時刻から実行するには

1. 設定画面の「開始時刻」で、未来の「入力補助の開始日時」を入れます。パソコンに表示されている時刻を基準にします。
2. **「保存して予約する」** を押します。日時を保存するだけでは予約は開始しません。
3. 練習ページの右下が「開始時刻を待機中」になったことを確認します。購入サイトで使うときは、そのサイトの設定画面から予約します。

「開始時刻に一度リロードする」は、予約した時刻になったときの最初の読み直しです。その後は、混雑の表示を見つけた場合にリロードします。通常の販売画面をずっと更新し続ける設定ではありません。

各操作が項目を待つ時間は、初期設定で45秒です。練習の「発売まで」を60秒にする場合などは、設定画面の「各操作の項目を待つ時間（秒）」を長くするか、発売開始に近い時刻から実行してください。PCのスリープやChromeの動作状況により、予約時刻より遅れることがあります。

## ほかに使える値の指定

この `{{...}}` の書き方を、設定画面では「変数」と呼びます。使う値を後から変更できる指定です。

| 指定 | 入る値 |
| --- | --- |
| `{{date}}` | 設定した目的の公演日 |
| `{{date+1}}` | 設定した目的の公演日の翌日 |
| `{{today+1}}` | 実行する日の翌日（パソコンの日付が基準） |
| `{{grade}}` | 設定した席種・グレード |
| `{{name}}` | 設定したお名前 |
| `{{email}}` | 設定したメールアドレス |
| `{{quantity}}` | 設定した枚数 |

チェック欄を覚えさせる場合は「チェックを切り替える」を選び、値を `true` にするとチェックを付け、`false` にすると外します。丸い選択ボタンは `true` で選択します。

## 止めたい・うまくいかないとき

- **途中で止めたい** ：右下のメニューで「停止」を押します。対象ページでEscキーを押しても止められます。記録中のEscは記録の取り消しにも使えます。
- **候補が複数ある** ：「対象に含まれる文字」に、その公演だけにある日付や席種を指定してください。勝手にどれかを選ぶことはありません。
- **項目が見つからない** ：公演日と席種が、練習条件とAutoReloadの設定で一致しているかを確認します。実サイトの場合は、対象があるページで教え直してください。
- **設定を編集したのに反映されない** ：「設定を保存」を押したか確認します。実行中に設定を変えたいときは、先に停止してください。
- **手で入力したら止まった** ：利用者の入力を検知すると、自動の処理は停止します。入力内容を確認してから必要な操作を開始し直してください。
- **購入を確定してくれない** ：最後の購入・申込確定は手動です。名前の似たボタンの見分け方はサイトによって異なるため、記録するボタンも自分で確認してください。
