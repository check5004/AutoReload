復旧監視・日時と席種の選択・入力補助を行う Chrome 拡張機能です。

0.2.0では、練習ページを拡張機能に内蔵しました。設定画面の **「練習ページを開く」** またはポップアップの **「練習ページ」** から、設定画面と同じようにタブで開けます。別サイト・別プログラムの起動は不要です。

- **AutoReload-v0.2.0.zip**：練習ページを含むChrome拡張機能。展開後の AutoReload フォルダーを使ってください。
- **SHA256SUMS.txt**：配布ファイルのSHA-256チェックサム。

内蔵ページでは、項目の記録・日付の変更・発売後の選択と入力・混雑ページの実リロードをオフラインで練習できます。練習設定は「内蔵の練習ページ」として購入サイト用の設定と分けて保存します。追加のサイトアクセス権限は不要です。

旧版のLab用ZIPと外部の練習サイトは不要になりました。旧サイト用の設定は保持されますが、内蔵ページには自動移行しません。

初回は `chrome://extensions` → デベロッパーモード → 「パッケージ化されていない拡張機能を読み込む」でインストールします。
更新は今までのフォルダーを上書きし、拡張機能と対象ページを再読み込みしてください。詳細は同梱の INSTALL.md を参照してください。

購入確定は手動です。まず内蔵の練習ページで設定と操作を確認してください。
