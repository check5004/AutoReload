前日に覚えて、当日は日付を変える。

まずは練習サイトで、操作の記録から混雑時の復旧まで試してみましょう。実際の購入・決済は発生しません。

1. 拡張機能を入れる

  1. GitHub Releases から AutoReload-vX.Y.Z.zip をダウンロードし、展開します。
  2. chrome://extensions で「デベロッパーモード」をONにし、「パッケージ化されていない拡張機能を読み込む」で AutoReload フォルダーを選びます。
  3. 練習画面をChromeで開き、拡張機能のアイコンからこのドメインをONにします。画面右下に ↻ が現れます。

2. 前日の操作を覚える

  1. 「前日の準備」で目的の公演日・席種を決め、練習を開始します。
  2. 拡張機能の「項目を覚える」を押し、目的の公演の「受付開始前」ボタンをクリックします。「対象に含まれる文字」に {{date}} | {{grade}} を入れて保存します。まだ押せないボタンも覚えられます。
  3. 「入力欄も準備する」でフォームを開き、お名前・メール・来場日・枚数をそれぞれ記録します。値は {{name}}、{{email}}、{{date}}、{{quantity}} を指定します。
  4. 必要なら「内容を確認する」もクリック操作として記録します。「購入を確定する」は記録できず、手動操作になります。
  5. 拡張機能の設定で、目的の日付・席種・名前などを保存します。「対象を確認」で一致する項目を青枠表示できます。
フォームに残っている練習用の値は、シナリオを開始し直すとリセットされます。拡張機能の設定は維持されます。

3. 発売開始を待つ

  1. 練習画面で「発売開始を待つ」を選び、同じ公演日・席種を設定して練習を始めます。
  2. 拡張機能の「入力補助を実行」を押します。最初は目的の公演が存在しませんが、発売開始後に見つけて進みます。初期の項目待機時間は45秒なので、練習の発売待ちを30秒以内にするか設定を調整します。
  3. ID・並び順を変える設定をONにしておくと、項目名や周辺情報から探し直す練習になります。
  4. 最終確認で内容を確認し、自分で「購入を確定する（練習）」を押します。

4. 混雑からの復旧を試す

  1. 「混雑からの復旧」で、復旧までの時間を設定し練習を始めます。
  2. 「アクセスが集中しています」という隔離画面になります。拡張機能の「復旧監視を開始」を押します。
  3. 設定時間を過ぎた後のリロードで公演画面に戻ります。リロードが止まり、パネルに「復旧しました」と表示されます。
  4. 混雑時に「入力補助を実行」を開始すれば、復旧後に記録した選択・入力も続けられます。

5. 開始時刻を予約する

設定画面でPCの現地時間の開始日時を保存し、「保存して予約する」かページ端の「時刻予約で実行」を押します。Chromeとタブを開いておき、PCをスリープさせないでください。開始時刻に一度リロードする設定も選べます。

本番サイトで使うとき

ドメインごとに操作を記録してください。ラベル・文字・周辺情報を使う認識で、サイト固有のすべてのUIに対応するものではありません。候補が複数ある場合は停止します。待機列・認証画面では画面の案内に従い、最終購入は自分で確認して進めます。
