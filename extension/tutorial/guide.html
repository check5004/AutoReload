前日に覚えて、当日は日付を変える。

この練習ページは拡張機能に内蔵されています。設定画面かポップアップの「練習ページ」から、通信やサイトへのアクセス許可なしで開けます。操作の記録や入力、復旧監視には実際の拡張機能と同じ処理を使います。

1. 前日の操作を覚える

  1. 「前日の準備」で公演日・席種を決め、練習を始めます。
  2. 画面端の ↻ パネルで「項目を覚える」を押し、目的の公演の「受付開始前」ボタンをクリックします。「対象に含まれる文字」は {{date}} | {{grade}} にして保存します。
  3. 「入力欄も準備する」からフォームへ進み、お名前・メール・来場日・枚数を順に覚えさせます。値は {{name}}、{{email}}、{{date}}、{{quantity}} です。
  4. 「内容を確認する」もクリック操作として記録できます。最後の「購入を確定する」は手動です。
  5. ページ上部の「練習用の設定を開く」で日付・席種・名前などを保存します。「対象を確認」では実行せずに候補を青枠で表示できます。
練習の操作と入力値は、設定画面の「内蔵の練習ページ」に保存されます。購入サイトごとの設定とは独立しています。

2. 発売開始を待つ

  1. 「発売開始を待つ」で、設定に保存した公演日・席種を選びます。日付だけ変える練習では、練習条件と設定の両方を同じ新しい日付にします。
  2. 発売までを15秒または30秒にして開始し、↻ パネルの「入力補助を実行」を押します。目的の公演は時間が来ると現れます。
  3. 「翌日は項目のID・並び順を変える」をONにすると、項目名や周辺情報から探し直す動作も確認できます。
  4. 最終確認まで進んだら内容を確認し、自分で「購入を確定する（練習）」を押します。

3. 混雑からの復旧を試す

  1. 「混雑からの復旧」を選び、復旧までの時間を指定して練習を始めます。
  2. 隔離画面が表示されたら、↻ パネルで「復旧監視を開始」を押します。
  3. 拡張機能がこのHTMLを実際に再読み込みします。復旧時間を過ぎた後の再読み込みで販売画面に戻り、監視が停止します。
  4. 混雑中に「入力補助を実行」を開始すれば、復旧後に記録した操作も続けられます。

4. 時刻を予約する

練習用の設定で開始日時を保存し、「保存して予約する」を押します。PCとChromeを起動し、練習タブを開いたままにしてください。「開始時刻に一度リロードする」も試せます。各操作の待機時間は初期値45秒です。

練習条件を最初に戻すには「練習をリセット」を押します。進行中の操作を止めて練習画面を初期化します。覚えた操作と設定は残ります。
